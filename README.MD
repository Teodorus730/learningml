# Learning ML

В этом репозитории собраны ноутбуки, посвященные самым разным темам из машинного обучения, глубокого обучения и связанной с этим математике. Они создавались в первую очередь чтобы разобраться в непонятной теме и "поиграться" с числами и визуализацией. Весь латех и почти весь код в репозитории написан руками (без использования ллм): основная идея в том, чтобы чему-то научиться (но могут быть и ошибки)

| Ноутбук | Тема |
|---|---|
| [softmax.ipynb](softmax.ipynb) | Трюки в реализации softmax |
| [self-attention.ipynb](self-attention.ipynb) | Подробно про attention и его реализации |
| [linal.ipynb](linal.ipynb) | Линейные преобразования, собственные векторы и SVD |
| [norm.ipynb](norm.ipynb) | Методы нормализации |
| [case-and-commas.ipynb](pet_projects/case-and-commas.ipynb) | Восстановление синтаксиса языка: двухголовый BERT |
